# Open Word Study

Free tools for reading the Greek New Testament and the Hebrew Old Testament more closely, built only from open data.
A side project and a work in progress, made by a member of Acts 2 Network Berkeley. It is not an official Acts2 Network
resource and is not affiliated with any Bible software company.

Live: https://vadneyk.github.io/open-word-study-site/

Sources and licences are in NOTICE.md. Pages that include unfoldingWord ULT, UST or Translation Notes content are shared
under CC BY-SA 4.0, as those sources require. Feedback is welcome through GitHub issues.
